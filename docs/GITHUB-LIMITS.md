# Verified rendering limits

Sources: https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image and https://github.com/github/markup . GitHub Markdown API probe removed custom position/z-index/user-select/border styles, escaped the stylesheet and removed object/inline SVG. SVG used as img does not receive hover events. An SVG may animate internally but cannot overlap other README blocks, control their layout or remove the browser text-selection highlight.

Theme-aware anchors remain with user approval, including for SVG previews. Main descriptive text and section headings are native Markdown and selectable. Badge/artwork lettering remains an image. Native image links and context menus are controlled by GitHub.

The contribution route is an original breadth-first-search implementation, informed by https://github.com/Platane/snk/blob/main/packages/solver/README.md . It repeatedly finds a shortest orthogonal route to the nearest unvisited active cell, then closes the circuit back to the start. It does not consume components or animate contribution data away.
