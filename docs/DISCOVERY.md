# Discovery files

`llms.txt` is a concise Markdown directory of the profile's public sources and the portfolio. It contains no hidden activity or tokens. It is an informational convention, not an access-control mechanism or a guarantee that a service will read it.

`robots.txt` permits crawling when deployed at a site's root. A file inside this GitHub repository does **not** control `github.com/efebedelcigil` or replace `github.com/robots.txt`. This repository is a GitHub profile, not the publishing source for the separate portfolio. No changes to that portfolio repository are made here. To apply a robots policy there, deploy an appropriate file at `https://efebedelcigil.github.io/robots.txt` through the portfolio's own publishing source.

Keep the portfolio and contact links in `llms.txt` consistent with `assets/profile.json` and `scripts/build_readme.py`. No live metrics are duplicated in this file, so scheduled updates cannot make its totals stale.

References: [robots.txt location and scope](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec), [llms.txt proposal](https://llmstxt.org/), [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
